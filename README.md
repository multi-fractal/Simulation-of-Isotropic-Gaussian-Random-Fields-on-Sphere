# Simulation-of-Isotropic-Gaussian-Random-Fields-on-Sphere

MATLAB scripts for the statistical simulation of isotropic Gaussian random fields on a sphere.

***random_field_sphere_modeling.m*** - simulation; 

***random_field_sphere_test.m*** - test.

**References**

C. Lantu_ejoul, X. Freulon, D. Renard (2019). Spectral Simulation of Isotropic Gaussian Random fields on a Sphere. Math. Geosci., 51, 999-1020.

D. Kolyukhin, A. Minakov (2022). Simulation of Gaussian random field in a ball. Monte Carlo Methods and Applications, 28(1), 85-95.
